<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket client → Durable Object | Any participant can send malformed, forged, repeated, or unauthorized commands. |
| Pages/Worker request → room instance | Room code and capability tokens select shared state. |
| Durable Object → D1 | Completed results cross from live state into durable storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-08 | Elevation of privilege | host command handlers | high | mitigate | Bind tokens to room and role and check host permission for every start/next/auto/resume/finish command. |
| T-03-09 | Tampering | answer/scoring handlers | high | mitigate | Ignore client score/time, use DO receipt time and Worker answer key, enforce deadline and unique answer key. |
| T-03-10 | Tampering/repudiation | reconnect handling | high | mitigate | Serialize opaque reconnect identity, restore it after hibernation, and never replay a missed answer. |
| T-03-11 | Denial of service | WebSocket command path | medium | mitigate | Cap frame size, validate message type before parsing/mutation, and rate-limit room actions/answers. |
| T-03-12 | Availability | host disconnect lifecycle | high | mitigate | Transition to paused_host_disconnect, freeze deadline accounting, and require the original host capability to resume. |
</threat_model>
