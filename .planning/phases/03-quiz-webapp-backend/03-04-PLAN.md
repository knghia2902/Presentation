<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public HTTP/WebSocket request → Pages Function | Untrusted headers, path segments, bodies, and upgrade requests enter the app. |
| Pages Function → DO/D1 bindings | Validated identity and commands cross into stateful/persistent services. |
| caller → `/api/score` | A caller may try to forge score, timing, correctness, or rank. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-13 | Tampering | `/api/score` | high | mitigate | Ignore posted score/timing and require a room capability before asking the DO for authoritative finalization. |
| T-03-14 | Elevation of privilege | room proxy | high | mitigate | Validate role-bound capability in the DO path and never authorize from nickname or query-string display data. |
| T-03-15 | Tampering | `/api/leaderboard` SQL | high | mitigate | Use D1 prepare/bind for every dynamic value and test the bounded ordering query. |
| T-03-16 | Denial of service | room/score/WebSocket routes | medium | mitigate | Cap request/frame size and rate-limit create/join/answer/finalization actions before forwarding. |
| T-03-17 | Information disclosure | error responses | medium | mitigate | Return stable Vietnamese-safe error messages without echoing tokens, raw SQL, or internal binding details. |
</threat_model>
